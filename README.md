# Khushboo Gupta Portfolio

A one-page portfolio recreated from the supplied visual reference, with the same editorial layout direction: cream paper background, oversized serif typography, pink ticker bands, asymmetrical work blocks, projects, extracurriculars, and contact section.

## Run
Open `index.html` in a browser. No build step is required.

The page uses Google Fonts (Cormorant Garamond and Montserrat). Cormorant is an open-source font family available through Google Fonts.

## Customize
Replace the placeholder content and the CSS portrait block with Khushboo's actual photo, project images, links, education, roles, achievements, and contact details.
